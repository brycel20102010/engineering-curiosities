[Astro](https://astro.build) is a website creation library that adds combines traditional html and css with attributes and the ability to use any UI framework. It uses [MDX](https://docs.astro.build/en/guides/integrations-guide/mdx/#mdx-in-astro), a modified version of markdown, for writing blog posts to allow addition of UI and javascript elements into a post. Since I'm not very familar with frontend web development, this site was based off the default 'blog' template with minimal CSS restructuring.

## Steps for making a new post
1. Complete a project worthy of making a post about.
2. Write content for that post.
3. Create a 960x480 image for the post.
4. Update site metadata (title, description, date).
5. Write a commit message and push to github.
